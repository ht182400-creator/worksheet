# 01 数据库结构文档

> 对应 V5.0 §26 数据模型。实现文件：`backend/app/db.py`（SQLAlchemy ORM）、`backend/app/store.py`（数据访问）。
>
> 默认 SQLite（`sqlite:///./work_order_system.db`），生产通过环境变量 `WORK_ORDER_DB_URL` 切到 PostgreSQL/MySQL，**索引与乐观锁约定不变**（§26）。

## 1. 总览

| 表名 | 中文 | 关键字段 | 对应章节 |
| --- | --- | --- | --- |
| `work_orders` | 工单主表 | `order_uuid`(PK)、`state`、`version` | §26.2 |
| `order_process` | 工序进度 | `order_uuid`、`process_code`、`completed_qty`、`version` | §26.3 |
| `reports` | 报工记录 | `report_id`(PK)、`status`、`withdrawable_until` | §26.4 |
| `conflict_logs` | 离线冲突记录 | `conflict_id`(PK)、`strategy`、`audit`(JSON) | §26.5 |
| `qrcode_print_tasks` | 二维码打印任务 | `print_task_id`(PK)、`state`(3a/3b) | §26.6 |
| `ocr_tasks` | OCR 任务 | `task_id`(PK)、`status`、`result`(JSON) | §26.7 |

## 2. 建表约定（DDL 语义）

- 主键：`work_orders.order_uuid`、`reports.report_id`、`conflict_logs.conflict_id`、`qrcode_print_tasks.print_task_id`、`ocr_tasks.task_id` 均为 `String(36)`（UUID v7 或 `uuid.uuid4()`，设计稿 §7.1 要求 UUID v7 作系统内部主键，`display_no` 仅展示）。
- 乐观锁：`work_orders.version`、`order_process.version` 为 `Integer` 自增，每次写后 `+1`；`version` 不一致则写失败（返回 `None` / 抛 `BusinessError`）。
- 时间：`created_at` / `updated_at` 统一 UTC（`datetime.utcnow()`，§25.1 时间约定）。
- 生产建表：当前 `init_db()` 仅骨架便利；**生产应由 Alembic 迁移执行**（§26 / §28 M0）。

## 3. 表结构明细

### 3.1 `work_orders`（工单主表，§26.2 / BR-16）

| 列 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `order_uuid` | String(36) | PK | 工单唯一标识（UUID） |
| `display_no` | String(32) | NOT NULL | 展示单号（人工可读） |
| `tenant_id` | String(36) | NOT NULL, INDEX | 租户隔离（BR-16）；生产 `UNIQUE(tenant_id, order_no)` |
| `state` | Integer | NOT NULL, DEFAULT 2 | 主状态 0-6（见 §02 状态枚举 / §03 状态机） |
| `version` | Integer | NOT NULL, DEFAULT 1 | 乐观锁版本号 |
| `doc_confidence` | Float | NULL | 整单 OCR 置信度（BR-20） |
| `need_review` | Boolean | NOT NULL, DEFAULT False | 是否需人工复核 |
| `created_at` | DateTime | NOT NULL | 创建时间（UTC） |
| `updated_at` | DateTime | NOT NULL | 更新时间（UTC） |

索引：`tenant_id`（多租户查询）、生产补充 `UNIQUE(tenant_id, order_no)`。

### 3.2 `order_process`（工序进度，§26.3 / BR-22）

| 列 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | Integer | PK, AUTOINCREMENT | 自增主键 |
| `order_uuid` | String(36) | NOT NULL, INDEX | 关联工单 |
| `process_code` | String(20) | NOT NULL | 工序编码 |
| `required_qty` | Integer | NOT NULL, DEFAULT 0 | 要求量（演示默认 `DEFAULT_DEMO_REQUIRED_QTY=100`，BR-05） |
| `completed_qty` | Integer | NOT NULL, DEFAULT 0 | 累计完成量（并发累加，BR-22） |
| `version` | Integer | NOT NULL, DEFAULT 1 | 乐观锁（CAS 累加合并语义） |
| `need_review` | Boolean | NOT NULL, DEFAULT False | 工序级复核标记 |

累加语义（§26.3）：报工提交时 `completed_qty += payload.completed_qty`，`version += 1`，原子提交；超报拦截 `completed_qty + 新增 > required_qty` → `BIZ_REPORT_OVERFLOW`(422)。

### 3.3 `reports`（报工记录，§26.4 / M5-12）

| 列 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `report_id` | String(36) | PK | 报工记录 ID |
| `order_uuid` | String(36) | NOT NULL, INDEX | 关联工单 |
| `process_id` | String(20) | NOT NULL | 工序编码 |
| `operator_id` | String(36) | NOT NULL | 操作人 |
| `completed_qty` | Integer | NOT NULL | 本条报工量 |
| `client_created_at` | DateTime | NULL | 客户端时间戳（离线场景） |
| `status` | String(16) | NOT NULL, DEFAULT 'VALID' | `VALID` / `WITHDRAWN` |
| `withdrawable_until` | DateTime | NULL | 撤回截止时间（`created_at + DEFAULT_WITHDRAW_WINDOW_MINUTES=30`） |

撤回窗口（M5-12 / §4.9.2）：`withdrawable_until` 之后或已进下工序 → `BIZ_WITHDRAW_EXPIRED`(409)。

### 3.4 `conflict_logs`（离线冲突记录，§26.5 / BR-06 / D7）

| 列 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `conflict_id` | String(36) | PK | 冲突 ID |
| `entity_type` | String(32) | NULL | 实体类型（如 `work_order`） |
| `entity_id` | String(36) | NULL | 实体 ID |
| `local_version` | Integer | NULL | 本地版本 |
| `server_version` | Integer | NULL | 服务端版本 |
| `strategy` | String(16) | NOT NULL, DEFAULT 'LOCAL_PENDING' | `LOCAL_PENDING` / `SERVER` / `MERGED` |
| `resolved_by` | String(36) | NULL | 裁决人角色 |
| `audit` | JSON | NULL | 审计信息（操作轨迹） |

默认 `LOCAL_PENDING`（本地优先待复核）；仅主管可裁决（D7 / `BIZ_PERMISSION_DENY` 403）。

### 3.5 `qrcode_print_tasks`（二维码打印任务，§26.6 / BR-21 / 3a-3b）

| 列 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `print_task_id` | String(36) | PK | 打印任务 ID |
| `order_uuid` | String(36) | NOT NULL, INDEX | 关联工单 |
| `state` | String(16) | NOT NULL, DEFAULT '3a_GENERATED' | `3a_GENERATED` / `3b_PRINTED` |
| `dpi` | Integer | NOT NULL, DEFAULT 300 | 分辨率（≥ `QRCODE_MIN_DPI=300`，BR-15） |
| `size_mm` | Integer | NOT NULL, DEFAULT 30 | 尺寸 mm（≥ `QRCODE_MIN_SIZE_MM=30`，BR-15） |
| `reprint_req_id` | String(36) | NULL | 重打请求关联（M3-02） |

3a→3b：`confirm_print` 将 `3a_GENERATED` → `3b_PRINTED`（BR-21）。

### 3.6 `ocr_tasks`（OCR 任务，§26.7 / BR-17 / 死信）

| 列 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `task_id` | String(36) | PK | 任务 ID |
| `status` | String(16) | NOT NULL, DEFAULT 'QUEUED' | `QUEUED` → `DONE` / `FAILED` |
| `result` | JSON | NULL | OCR 结构化结果（字段级置信度，BR-20） |
| `created_at` | DateTime | NOT NULL | 创建时间（UTC） |

上传异步入队返回 `taskId`（BR-17）；轮询终态。演示 `get_ocr_task` 直接返回 `DONE` 样例（含 `fields` 置信度）。
生产补充：失败重试 / 死信队列（§26.7）。

## 4. 关系图（ER）

```
work_orders 1 ──< order_process       (order_uuid)
work_orders 1 ──< reports             (order_uuid)
work_orders 1 ──< qrcode_print_tasks  (order_uuid)
work_orders 1 ──< conflict_logs       (entity_id，弱关联)
ocr_tasks      独立（task_id 关联上传请求，不绑定工单）
```

## 5. 生产切换要点（§26 / §28）

- 改 `WORK_ORDER_DB_URL` 指向 PostgreSQL/MySQL；`check_same_thread` 仅 SQLite 需要。
- `init_db()` 仅用于骨架；生产用 Alembic 迁移，保证 `version` 乐观锁列与索引一致。
- `String(36)` 主键在 PG 用 `CHAR(36)` 或 `UUID` 类型；索引 `tenant_id` 必建。
