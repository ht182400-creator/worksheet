## 关键约定速查

- **统一响应体**：成功 `{"code":"0","data":...,"traceId":...}`；业务错误 `{"code":"BIZ_*","message":...,"traceId":...}`（§25.1）。
- **乐观锁**：`work_orders.version` / `order_process.version`，`PATCH /status` 与报工均校验 `version`，冲突返回 `409 BIZ_VERSION_CONFLICT`（BR-18）。
- **多租户**：`tenant_id` 隔离（BR-16），当前骨架未强制注入，生产按 §13 拦截器实现。
- **状态机**：唯一权威源 `state_machine.py`，前端按钮由 `state-machine` 端点驱动，禁止硬编码（D3）。
- **CI/CD**：每次合并后自动跑冒烟测试集合，未通过**阻断 MR**（详见 §06）。
